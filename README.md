# User Activity Prediction

Этот проект состоит из серии ноутбуков, в которых шаг за шагом исследуются основные алгоритмы машинного обучения: от простой логистической регрессии до кластеризации и работы с реальными сценариями. Данные проекта находятся в папке `data`.

## Структура проекта

### ex00  
**00_binary_classifier_logreg.ipynb**  
- Первая попытка бинарной классификации.  
- Фичи: количество коммитов до и после полудня.  
- Алгоритм: Logistic Regression.  

### ex01  
**01_binary_classifier_svm_tree.ipynb**  
- Улучшение бинарного классификатора.  
- Изучение логистической регрессии «под капотом».  
- Новые алгоритмы: SVM и Decision Tree.  
- Визуализация решений.  

### ex02  
**02_multiclassi_one-hot.ipynb**  
- Переход от бинарной классификации к мультиклассовой.  
- Работа с категориальными признаками (One-Hot Encoding).  
- Алгоритмы: Random Forest + анализ важности признаков.  
- Практика: предсказание дня недели коммита.  

### ex03  
**03_split_crossval.ipynb**  
- Работа с переобучением.  
- Train/Test Split и K-Fold Cross-Validation.  
- Объяснение, почему 100% accuracy — не всегда хорошо.  

### ex04  
**04_regression.ipynb**  
- Задача регрессии.  
- Предсказание среднего дельта-времени между дедлайном и первым коммитом.  
- Использование числовых признаков активности пользователей.  

### ex05  
**05_clustering.ipynb**  
- Неподконтрольное обучение (Unsupervised Learning).  
- Алгоритмы кластеризации.  
- Разделение пользователей на группы для дальнейшего анализа.  
- Идея: использовать сегментацию для персонализированных механик.  

##  Данные проекта

Папка `data` содержит следующие файлы:  
- `am_pm.csv` — количество коммитов до и после полудня  
- `checker_regression.csv` — данные для проверки модели регрессии  
- `checker_submits.csv` — данные о коммитах пользователей  
- `checker_timestamps.csv` — временные метки коммитов  
- `dayofweek.csv` — день недели каждого коммита  
- `regresion.csv` — данные для задачи регрессии
